# Kalyana v6.4.0 — Reference Match

Fokus revisi ini adalah dua layar yang dilampirkan pengguna: **Project Saya / Project usaha** untuk UMKM dan **Pekerjaan Saya** untuk mahasiswa.

Perubahan visual utama:
- Sidebar dikunci 247 px seperti referensi.
- Topbar 80 px dan judul ganda di topbar disembunyikan.
- Konten dimulai pada posisi dan jarak yang lebih dekat ke referensi 1231×967.
- Tiga kartu statistik memakai ukuran, gap, icon box, tipografi, dan radius yang disetel ulang.
- Kartu grafik memakai proporsi kiri/kanan 44/56, donut 142 px, legend, dan progress gradient.
- Daftar project disusun: Berjalan → Menunggu → Selesai, sesuai screenshot.
- Tombol aksi tambahan yang sebelumnya mengubah tampilan referensi dihilangkan dari layout utama.
- Pada mahasiswa, editor progress dipindahkan ke dialog yang muncul saat baris pekerjaan diklik.
- Pada UMKM, project berstatus Menunggu dapat dimulai dengan klik badge Menunggu.
- Form Buat project baru tetap berada di kolom kanan seperti screenshot.

Fungsi backend dan test sebelumnya dipertahankan.
